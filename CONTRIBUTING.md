# Contributing to meerCAD

Thanks for wanting to help.

**Issues are welcome:** bug reports, ideas, questions and examples of parts that do not build the
way you expect. Please include the steps, the device and, if you can, the `.meercad` file.

**Pull requests are not accepted at the moment.** meerCAD is sold through the App Store by
Torben Berger UG (haftungsbeschränkt), so all of its code has to come from the company. If you have
found a fix, describe it in an issue; a short code snippet there is fine.

You may of course change and build meerCAD for yourself (see "Build it yourself" in the README).
