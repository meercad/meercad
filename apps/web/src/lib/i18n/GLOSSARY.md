# German terms

The interface speaks to the user with "du" (lowercase), in short, plain sentences. Key names stay
as they are (Shift, Esc, ⌘, Enter → Eingabe only in prose). Units and numbers stay unchanged
(decimal point, because inputs take it). Product names stay: meerCAD, iCloud, LiDAR, STEP, STL, 3MF,
DXF, SVG, PDF, MCP.
